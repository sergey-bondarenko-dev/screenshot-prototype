# Region Shot

Статическое демо захвата произвольной области вкладки: Screen Capture API → замороженный кадр → выделение → модалка с превью → скачивание PNG.

Изображения не отправляются на сервер. Галерея хранится в памяти до обновления страницы. Демонстрация включает движущийся Canvas и WebGL в sandboxed iframe с отдельным origin.

## Публикация

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Ожидаемый адрес после включения Pages: https://sergey-bondarenko-dev.github.io/screenshot-prototype/

Сборка и Node.js не требуются: все файлы находятся в корне.

## Использование

Открыть демо в настольном Chrome/Edge по HTTPS, нажать «Сделать скриншот», разрешить захват текущей вкладки, выделить область и нажать «Сохранить» в модалке. Escape отменяет выделение. Папка скачивания зависит от настроек браузера.

Захват осуществляется через видеопоток браузера, без html2canvas и без чтения DOM сторонних iframe или пикселей Canvas/WebGL игры. Захватывается видимая часть выбранного источника. Браузер всегда требует разрешение пользователя; автоматически выбрать вкладку нельзя. DRM, политики ОС и аппаратные особенности могут ограничивать захват. Внешние сайты могут запрещать встраивание в iframe. Совместимость с конкретной игрой нужно проверять отдельно.

Для встраивания импортировать RegionShot из region-shot.js и создать new RegionShot({ endpoint: null, onCaptured({blob,width,height}) { /* локальные превью */ } }).
